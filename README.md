# Pipeline

Post-treatment of simulations using GR1D and FLASH.

## Description

This project is designed for the post-treatment of simulation data generated by GR1D and FLASH. It processes the data to extract usual figures, e.g.

-Shock radius +PNS radius
-Neutrino luminosity + energy
-Gravitational waves (Thanks to Haakon Andresen for the treatment!)
-Expected neutrino detections

## Installation

depends on packages:

-yt

-h5py

-matplotlib

-scipy

-Snewpy and Snowglobe (this part can be commented out in Main.py)


## Usage

In Shared.py:

-<FLASH_path> is the path to your FLASH simulations .dat file 

-<output_path> is the path to the output directory of your FLASH simulations if different than <FLASH_path>

-<GR1D_path> is the folder in which your GR1D simulations results are

Choose what you want to do in Main.py

Normally self-descriptive, but will add later stuff

Launch by using : python3 Main.py
